# Contributing to FVA

Welcome! We're excited that you're interested in contributing to the FVA project. Your contributions help improve the tool and make multimedia data management easier for everyone.

## Ways to Contribute
There are several ways you can contribute:
- **Bug Reports**: If you encounter any issues, please let us know by opening a bug report.
- **Feature Ideas**: We welcome suggestions for new features or enhancements.
- **Documentation**: Help us improve our documentation by suggesting edits or adding new content.
- **Code**: If you're comfortable with C++, feel free to dive into the code and submit improvements or fixes.

## Setting Up the Project Locally
To set up and run the project locally, follow these general steps:
1. Clone the repository:
   ```
   git clone https://github.com/dimanikulin/fva.git
   cd fva
   ```
2. Install the necessary dependencies as outlined in the README.
3. Build the project using the appropriate build tools for C++.
4. Run the application to test your changes.

## Submitting a Pull Request
To submit a pull request, please follow these steps:
1. Fork the repository.
2. Create a new branch for your feature or bug fix:
   ```
   git checkout -b my-feature-branch
   ```
3. Make your changes and commit them:
   ```
   git commit -m "Description of my changes"
   ```
4. Push your branch to your fork:
   ```
   git push origin my-feature-branch
   ```
5. Open a pull request in the original repository.

## Code Style
Please adhere to the code style guidelines provided in the project documentation. Consistency in style helps maintain readability and quality in the codebase.

Thank you for considering contributing to FVA! Your help is greatly appreciated.
